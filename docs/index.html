Everything the handheld did. Then some.

A native Kotlin app built around mGBA, one of the most accurate GBA emulators there is.

Accurate emulation

The mGBA core handles the CPU, graphics, sound, DMA, timers, and SRAM, Flash and EEPROM saves, plus the real-time clock some games rely on.

Real fast-forward

Frames really run 2×, 3×, 4× or 8× faster, or as fast as your phone allows. Hold to speed up, or tap to toggle it.

Save states

Nine slots plus Auto, with thumbnails, quick save and load, and export and import. It always asks before overwriting. Your in-game saves stay separate.

Your library

Games stay where they already are on your device. MicroBoy tracks recently played, playtime and box art.

Touch controls

Multi-touch and themed, with haptics. Move and resize every button, with separate layouts for portrait and landscape.

Controllers

Bluetooth and USB gamepads work right away, and every button can be remapped.

Display options

Fit, integer or stretch scaling. Scanline, LCD-grid and CRT filters, smoothing, brightness, saturation and GBA color correction.

Low-latency audio

AAudio output with dynamic rate control, so sound stays in sync without crackles. The game pauses when you unplug your headphones.

Eleven themes. Try one on.

These are the app's own color themes. Pick one and this page changes to match.

The app also has a fully custom theme with an HSV color picker, and on Android 12+ it can follow your wallpaper colors.

How MicroBoy compares

These are the four best-known GBA emulators on Android. They're all good, and here's how MicroBoy stacks up, including what it doesn't do yet.

mGBA, in an app built only for GBA

Lemuroid and RetroArch also run mGBA, but inside frontends built for dozens of systems. My Boy! and Pizza Boy use their own cores. MicroBoy is the only one of these that pairs mGBA with an app designed only for GBA.

Everything included, for 50¢

There's no Pro tier and no locked features. It costs about a tenth of the other paid GBA apps, and the source is public, so you can build it for free.

Your saves are hard to lose

In-game saves and save states are kept completely separate, and loading a state never overwrites your in-game save. You get nine slots plus Auto, each with a thumbnail, and MicroBoy asks before overwriting anything.

It looks like yours

Eleven themes, a custom theme with an HSV picker, and your wallpaper's colors on Android 12+. The theme colors the menus and the on-screen controller too.

Build it yourself

These steps work on Linux, macOS, or Windows with Git Bash. The first build takes a few minutes, because it compiles mGBA for three CPU types.

  1. Install the tools

    You need JDK 17 and the Android SDK; installing Android Studio gets you both. Gradle downloads the right platform, NDK (27.2.12479018) and CMake (3.22.1) on the first build, once you have accepted the SDK licenses:

    sdkmanager --licenses

  2. Get the source

    Include --recursive, which also downloads the mGBA core.

    git clone --recursive https://github.com/M4S4T0-V01D/GBA-Emulator.git
cd GBA-Emulator

  3. Point it at your SDK

    echo "sdk.dir=$HOME/Android/Sdk" > local.properties

  4. Build

    ./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk

    Without a keystore of your own, the build is signed with your debug key, which is fine for sideloading.

  5. Install

    Copy the APK to your phone and open it, allowing installs from that app when Android asks. Or, with USB debugging on:

    adb install app/build/outputs/apk/release/app-release.apk

Questions

Does MicroBoy come with games?

No. MicroBoy includes no games and no BIOS. Use backups of games you own.

Do I need a BIOS file?

No. mGBA has a built-in BIOS replacement that runs nearly every game. You can choose your own BIOS dump in Settings if you prefer.

Can I bring saves from another emulator?

Yes. Each game's info screen can import and export a standard .sav file, and save states can be exported and imported too.

Which phones does it run on?

Any phone or tablet running Android 8.0 or newer, on 64-bit ARM, 32-bit ARM or x86_64 (Chromebooks and emulators).

Does it collect any data?

No. There are no accounts, ads or analytics. The only network feature is an optional box-art download, which is off by default. See the privacy policy.

Why pay if I can build it for free?

Convenience. The Play version installs in one tap and updates on its own. Paying also supports development. If you'd rather build it, go ahead.
